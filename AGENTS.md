# AGENTS.md

## Notes for humans and agents (hand-written)

- `packages/core` is the only place standards live. CLI, Action, Worker and MCP are thin surfaces over it; never duplicate a check in a surface.
- Controls are deterministic pure functions of a `Snapshot`. Do not call a model, the network or the clock (use the injected `now`) from a control.
- Tri-state results matter: return `unknown` with a reason when you cannot decide; never guess `pass`. Transient GitHub errors must throw (they carry `transient: true`), not become `unknown`.
- Never echo a matched secret value in evidence. Show the file, line and a short prefix only.
- Tests use Node's runner: `npm test`. After changing a control or its text run `npm run docs`; after touching `packages/core`, `packages/cli` or `action/`, run `npm run build` and commit `action/dist` (CI fails on a stale bundle).
- Repo-derived strings are untrusted. Render them with the helpers in `packages/core/src/format.ts` (markdown) or `textContent` (UI); never `innerHTML`.
